# Sketch Studio

Freehand sketching desk built on **Novolis.Avalonia.Controls** `SketchControl`.

Tools: Pen, Line, Spline, Box, Circle, Eraser, Select  
Options: Snap to grid, Meetup (vertex snap), Gridify, stroke color + width  
Documents: Open / Save / Save As as `.sketchjson`  
Clipboard: Copy PNG (opaque), Copy SVG

```powershell
dotnet run --project src/SketchStudio
```

Shortcuts: `Ctrl+N/O/S`, `Ctrl+Shift+S`, `Ctrl+Z/Y`, tool keys `P/L/S/R/C/E/V`, `Del` deletes selection.
