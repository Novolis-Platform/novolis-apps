# Vision

Sins of a Capitalism Tycoon is a **campaign-scale economic dogfood**: one hundred systems
near Sol, hop-linked freight, firms and households that must pay, haul, stock, and settle.

The “sins” are ordinary: thin working capital, narrow logistics residual, fiscal overreach,
leverage that looks solvent until due-now arrives, insurance that redistributes loss without
erasing it. The mind-boggling part is not spectacle. It is **causality made scannable** —
Ops ledgers, Core stocks, corridor loads, and agent decisions in one report after a long run.

## What this app is not

- Not a 4X conquest UI (Avalonia StarMap is later).
- Not a second money stock. Ops FirmLedgers and Core vault/deposits are labeled separately
  and never summed into one “total cash.”
- Not abstract policy theater. Like founding container standards, the interesting machinery
  is dimensions, locks, plates, inspections, and patience — here: capacity, tolls, berths,
  obligations, and deterministic seeds.

## Success criterion

After `10d` / `100d` / `1000d` headless, an operator can answer: who holds liquid claims,
where cargo sits or stalls, which agents last decided what, and whether Core still
conserves what Core claims to conserve.
